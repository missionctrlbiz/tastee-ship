# rules.md — Bean Street × Pumpkin Patch (owner taste, v2)

The season is ON. The pumpkin patch is the product — build it bold, build it working.

## Product
- One-page coffee-shop site WITH a seasonal pumpkin patch.
- The carving studio must actually work: live canvas, candle glow, save as PNG, add to order.
- The order form must always work; carved pumpkins ride the same ticket as drinks.

## Taste
- Autumn palette (espresso/cream/ember/vine), mobile-first, no feature without function.
- No frameworks; plain HTML/CSS/JS; motion honours prefers-reduced-motion.

## Hard "no" list
- No Comic Sans. No lorem filler. No decorative stubs that pretend to be features.
